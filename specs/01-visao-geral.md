# Visão Geral do Produto

## Nome do Projeto
**TaskFlow** - Sistema de Gerenciamento de Tarefas Pessoal

## Descrição
Aplicação web full-stack para gerenciamento de tarefas pessoais com organização por projetos, prioridades, tags e datas de vencimento. Foco em simplicidade, usabilidade e produtividade.

## Objetivos
- Permitir criação, edição, exclusão e listagem de tarefas
- Organização por projetos/categorias
- Sistema de prioridades (Baixa, Média, Alta, Urgente)
- Tags personalizadas para filtros avançados
- Datas de vencimento com alertas visuais
- Dashboard com estatísticas de produtividade
- Persistência de dados local (localStorage) e opcional backend

## Público-Alvo
Usuários individuais que buscam uma ferramenta leve e eficiente para organização pessoal de tarefas.

## Stack Tecnológica
- **Frontend**: React 18 + TypeScript + Vite
- **Estilização**: Tailwind CSS
- **Estado**: Zustand (gerenciamento de estado leve)
- **Roteamento**: React Router v6
- **Build**: Vite
- **Lint/Format**: ESLint + Prettier
- **Testes**: Vitest + React Testing Library
- **Deploy**: Vercel / Netlify (configuração pronta)
