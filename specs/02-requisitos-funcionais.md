# Requisitos Funcionais

## RF-01: Gerenciamento de Tarefas
| ID | Requisito | Prioridade |
|----|-----------|------------|
| RF-01.1 | Criar nova tarefa com título, descrição, prioridade, data de vencimento, projeto e tags | Alta |
| RF-01.2 | Editar tarefa existente | Alta |
| RF-01.3 | Excluir tarefa com confirmação | Alta |
| RF-01.4 | Marcar tarefa como concluída/pendente | Alta |
| RF-01.5 | Listar tarefas com filtros (status, prioridade, projeto, tags, busca textual) | Alta |
| RF-01.6 | Ordenar tarefas (data criação, vencimento, prioridade, alfabética) | Média |

## RF-02: Gerenciamento de Projetos
| ID | Requisito | Prioridade |
|----|-----------|------------|
| RF-02.1 | Criar projeto com nome, cor e ícone | Alta |
| RF-02.2 | Editar projeto | Média |
| RF-02.3 | Excluir projeto (mover tarefas para 'Sem projeto') | Média |
| RF-02.4 | Listar projetos com contagem de tarefas | Alta |

## RF-03: Tags
| ID | Requisito | Prioridade |
|----|-----------|------------|
| RF-03.1 | Criar tags personalizadas com cor | Média |
| RF-03.2 | Associar/desassociar tags às tarefas | Média |
| RF-03.3 | Filtrar tarefas por tags | Média |

## RF-04: Dashboard e Estatísticas
| ID | Requisito | Prioridade |
|----|-----------|------------|
| RF-04.1 | Exibir total de tarefas (pendentes, concluídas, atrasadas) | Alta |
| RF-04.2 | Gráfico de produtividade semanal | Média |
| RF-04.3 | Tarefas vencendo hoje/esta semana | Alta |
| RF-04.4 | Distribuição por prioridade/projeto | Média |
